# Startrack 0.1.31 · нативный Rust/GTK

- Обрезка аватарок и баннеров с масштабом и перемещением. Анимация GIF сохраняется.
- Трей: скрытие окна, открытие, полный выход. Настраиваемый автозапуск Windows/Linux.
- Инструменты Верити для файлов, команд и программ с нативными разрешениями и остановкой.
- Необязательная передача системного звука при демонстрации экрана.
- Отдельный канал подписанных обновлений для нативных сборок, прогресс скачивания и резервная копия при установке.

Android и встроенные YouTube/Spotify остаются отдельным этапом. Подробные ограничения системного звука, Linux и обновлений — в README клиента.
