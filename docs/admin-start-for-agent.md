# Startrack admin panel: запуск для AI-агента

## Цель

Открыть удалённую админку Startrack с Windows-ПК пользователя. Админка работает на сервере `185.218.0.111` и слушает только `127.0.0.1:8081`. Публичного доступа к этому порту нет: нужен SSH-туннель.

## Что сделать

1. В PowerShell запустить туннель и оставить окно/процесс работающим:

   ```powershell
   ssh -i "$HOME\.ssh\startrack_ed25519" -N -L 8081:127.0.0.1:8081 root@185.218.0.111
   ```

   Если SSH спросит подтверждение fingerprint нового сервера, остановиться и показать вопрос пользователю. Если появится ошибка аутентификации или подключения, сообщить её пользователю.

2. Открыть в браузере `http://localhost:8081`.

3. Для входа нужен `ADMIN_TOKEN` из `/opt/startrack/.env` на сервере. Получить только значение токена командой:

   ```powershell
   ssh -i "$HOME\.ssh\startrack_ed25519" root@185.218.0.111 "grep '^ADMIN_TOKEN=' /opt/startrack/.env"
   ```

   Не записывать токен в репозиторий, этот файл, логи или сообщения. Вводить его только на открытой странице `http://localhost:8081`. Если политика UI-автоматизации требует передать пользователю ввод пароля/секрета, попросить пользователя вставить токен самостоятельно.

4. Убедиться, что страница админки загрузилась и после входа показалась панель управления. Если локальный порт занят, использовать свободный порт слева, например `-L 8082:127.0.0.1:8081`, и открыть `http://localhost:8082`.

## Остановка

Когда админка больше не нужна, завершить SSH-туннель: в окне PowerShell нажать `Ctrl+C` или завершить запущенный процесс SSH.

## Если админка не отвечает

Проверить состояние API на сервере:

```powershell
ssh -i "$HOME\.ssh\startrack_ed25519" root@185.218.0.111 "systemctl status startrack-api --no-pager"
```

Проверить сообщения запуска админки:

```powershell
ssh -i "$HOME\.ssh\startrack_ed25519" root@185.218.0.111 "journalctl -u startrack-api -n 50 --no-pager"
```

Админка выключена, если `ADMIN_TOKEN` отсутствует или короче 16 символов. Не запускать установочный `setup.sh` только ради диагностики: он может перезапустить другие сервисы. При проблеме сначала показать пользователю конкретную ошибку.
